# BANDO HUB Tauri + Rust v0.0.2

기존 Windows Tauri **v0.0.1의 실제 실행과 상품 가격 수정/재실행 후 저장 유지**는 사용자 기기에서 확인되었습니다. 이번 v0.0.2는 **주문 접수 및 수동 분류의 Rust 저장 경계 보강**을 위한 별도 소스 업데이트입니다. 이 ZIP은 EXE가 아닌 **전체 소스**입니다.

## v0.0.2 변경

- 기존 React **접수 화면, 자동 파서, 수동 분류 UI**를 유지합니다. 이번에 새 UI를 다시 구현한 것은 아닙니다.
- 새 주문은 `주문 확인 완료` 전까지 SQLite의 정식 주문에 기록하지 않도록 Rust에서 추가 검증합니다.
- 확정 시 거래처, 상품/옵션, 수량, 수취인별 배송 건, 확정 이벤트, 스냅샷/원문 일치 여부를 검증합니다. UI에서 수행하는 모든 업무 검증을 Rust로 완전히 이전한 단계는 아닙니다.
- 확정된 원문, 확정 시각, 최초 스냅샷, 주문 유형 및 송하인 스냅샷의 변경을 제한합니다.
- 확정 주문과 이후 접수 정정 내용을 `receipt_archive` SQLite 테이블에 독립적으로 기록하고, 설정의 **접수 원문 감사 보관함**에서 조회하도록 연결했습니다.
- `order_index` 검색용 SQLite 테이블을 추가했습니다. 기존 `app_state` JSON과 같은 트랜잭션에서 갱신합니다.
- 중복 주문 ID 및 기존 정정 기록의 삭제/수정 방어를 추가했습니다.
- 상품 303개/옵션 360개 시드는 그대로 유지합니다.
- Tauri 앱 식별자 `com.bandostand.bandohub.tauri` 및 DB 파일명 `bando-hub-v001.sqlite` **변경 없음**: v0.0.1에서 수정한 상품 가격을 초기화하지 않습니다.

## Windows 빌드

1. 기존 `BANDO-HUB-v0.0.1.exe`와 해당 프로젝트 소스는 백업해 둡니다.
2. 이 ZIP을 **별도 새 폴더에 압축 해제**합니다. 기존 `release` 폴더에 소스파일을 덮어쓰지 마세요.
3. `BUILD_WINDOWS_TAURI.cmd` 실행. Node.js 22+, Rust stable, Visual Studio C++ 빌드 도구 및 WebView2 런타임이 필요합니다.
4. 성공 시 `release/BANDO-HUB-v0.0.2.exe`를 실행합니다.
5. Tauri 실행파일은 실행 때마다 압축을 해제하는 self-extracting Portable 형식이 아닙니다.

**가격 데이터를 유지하기 위해** 기존 Tauri 앱 데이터 폴더를 삭제하지 마세요. 새 버전으로 업데이트할 때 `src-tauri` 아래의 DB 파일을 직접 덮어쓸 필요는 없습니다.

## Windows 수동 기능 검증 순서

1. v0.0.2 실행, v0.0.1에서 변경한 상품 가격이 유지되는지 확인합니다.
2. 거래처 관리에서 테스트 거래처를 등록합니다. 기존 v0.0.1의 거래처 데이터는 별도로 이관할 필요가 없습니다.
3. `접수`에서 발주서 원문을 입력하고 수취인/상품 인식을 확인합니다.
4. 필요한 경우 `수동 분류`에서 수취인, 주소, 연락처, 상품, **수량**을 채웁니다.
5. `주문 확인 완료`를 진행하고, 앱을 종료했다 다시 실행해 주문/배송 건이 유지되는지 확인합니다.
6. `설정`의 `접수 원문 감사 보관함`에서 해당 주문의 최초 원문 기록을 확인합니다.
7. 테스트를 위해 접수 전 초안 저장 시 정식 주문으로 들어가지 않는지, 확정 후 원문을 수정하려 하면 차단되는지 확인합니다.

**주의:** 현 Linux 작업 환경에는 Rust/MSVC/Windows 실행 환경이 없어 실제 `cargo test`, Windows EXE 빌드, 종단 간 UI 시험을 실행하지 못했습니다. 위 절차는 사용자의 Windows에서 확인해야 합니다. `npm test`는 소스/시드 정적 검사를 수행하며 Rust 비즈니스 로직 검사를 대신하지 않습니다.

Rust 단위 테스트는 Windows에서 다음 명령으로 별도 실행할 수 있습니다.

```powershell
cargo test --manifest-path src-tauri/Cargo.toml
```

## 제외/남은 항목

- 카카오톡 Windows 창 도킹, 공장 Excel 내보내기 및 공장 회신, 거래처/상품 XLSX 일괄 가져오기 등 Electron API 의존 기능은 아직 Rust로 이전하지 않았습니다.
- 웹 ChatGPT 전용 브라우저, MCP, AI 발주 분석, OCR AI 보조는 사용자 결정에 따라 **보류**이며 이번 소스에서 손대지 않았습니다.
- `captureReceipt` 및 `recordReceiptCorrection` 직접 IPC 호출은 여전히 미지원입니다. 원문 보관은 **정식 주문 저장 시 Rust의 자동 아카이브 경로**로 처리합니다.
- 완전한 감사 무결성 보장, DB 백업 복구 시 감사 이력 합치기, 보안 검증은 별도 단계입니다.
- 실운영에 투입하기 전 Windows에서 기능별 검증이 필요합니다.
