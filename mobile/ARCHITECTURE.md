# 스마트폰 업무 앱 연결 구조

현재 PC Electron 화면과 `src/domain.ts`의 파서·가격·메시지 로직은 React 기반으로 재사용할 수 있습니다. 화면은 작은 너비에서 세로 배치됩니다.

`mobile/transport.ts`는 향후 동일 SQLite 서버에 연결할 때 사용할 HTTPS 전송 경계입니다. 인증 세션 확인, CSRF 토큰, 버전 확인, ETag/If-Match 동시 수정 검사를 먼저 통과해야 데이터를 읽거나 저장할 수 있습니다. 인증되지 않은 연결이나 HTTP 주소는 허용하지 않습니다.

이번 배포는 이 전송 경계를 PC 화면에 활성화하지 않았습니다. 사용자 계정·권한 관리, HTTPS 인증서/회사 도메인 또는 VPN, 세션 쿠키 보안, 서버 측 검증 및 모바일 실제 기종 테스트가 아직 준비되지 않았습니다. 회사 PC의 HTTP 주소나 기존 단일 수신 토큰을 외부 인터넷에 공개하지 않았습니다.

다음 단계는 PC 서버에 위 인증 API를 구현한 뒤 동일 React 화면을 PWA 셸로 제공하는 것입니다. 주문·고객정보는 서비스워커 캐시에 저장하지 않는 정책을 사용합니다. 정적 화면만 오프라인 캐시하고 실제 데이터는 로그인 후 서버에서 읽습니다.

기존 LAN 텍스트·사진 수신은 이전 버전과의 호환을 위한 보조 기능으로 남아 있으며, 스마트폰 전체 주문관리 기능을 완료한 것으로 간주하지 않습니다. 유료 클라우드나 외부 공개를 구성하지 않았습니다.
