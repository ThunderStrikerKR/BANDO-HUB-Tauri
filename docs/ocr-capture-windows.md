# 반도허브 Windows OCR: 화면 범위 지정

## 사용 방식
발주 원문의 `캡처 범위 지정` 버튼을 클릭하면 Windows 기본 선택 UI(Win+Shift+S)가 열립니다.
화면의 필요한 부분을 마우스로 지정하면 지정 이미지에 대해 로컬 PaddleOCR PP-OCRv5 한글 모델로 문자를 추출합니다.

1. 직원이 화면에서 사각형 캡처 범위를 선택합니다.
2. 캡처 이미지와 편집 가능한 OCR 문자열이 검토창에 표시됩니다.
3. 직원이 확인하고 `원문 교체` 또는 `원문에 추가`를 선택해야 기존 발주서 분석기로 전달됩니다.
4. `취소`하면 현재 발주 원문과 주문 데이터는 변경되지 않습니다.
5. 기존 원문을 교체할 경우 별도의 확인창을 표시합니다.

## 설치
- Windows PC에서 Python 3.11 x64가 필요합니다.
- 저장소의 `SETUP_OCR_WINDOWS.cmd`를 최초 1회 실행합니다. 이 단계만 인터넷에 연결해 패키지와 모델을 받습니다.
- Python 실행환경 경로: `%LOCALAPPDATA%\BandoHub\OCR\venv\Scripts\python.exe`
- 모델 캐시가 준비되면 직원 PC에서 직접 OCR을 실행합니다. 클라우드 API나 월 구독 비용이 없습니다.
- 반도허브 EXE에는 Python 패키지 및 모델 가중치가 내장되지 않았으므로 Windows PC별 초기 설정이 필요합니다.

## 개인정보 및 안정성
- 캡처 이미지, 인식 초안과 임시 결과는 DB에 자동 저장하지 않습니다.
- 운영체제 클립보드에 먼저 저장되어 있던 과거 이미지는 OCR 입력으로 사용하지 않습니다.
- 지정한 이미지에 대한 임시 BMP 및 OCR 처리 출력은 작업 종료 시 삭제합니다.
- 모델 인식 실패나 캡처 미완료 시 기존 주문 데이터는 변경하지 않습니다.
- 확정 주문에는 OCR 원문 변경 기능을 제공하지 않습니다.
- 실제 Windows 화면 캡처, OCR 정확도, Python 가상환경, EXE 통합 테스트는 별도 실기기 검증이 필요합니다.

현재 범위는 `캡처 범위 지정`을 통한 OCR입니다. 폴더 자동 감시 기능은 포함하지 않습니다.
