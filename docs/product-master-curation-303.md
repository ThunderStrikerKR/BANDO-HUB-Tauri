# BANDO HUB 상품명 및 상품설명 303건 개별 정리 검수표

## 검토 범위와 주의
- 기준: Tauri `feature/tauri-product-bulk-registration` 개발 브랜치의 초기 상품 데이터.
- 자료 출처: `src-tauri/resources/catalog.json`의 역사적 원본 상품명 및 `src-tauri/resources/state-seed.json`에 보존된 상품 정보.
- 완료한 편집: **303개 상품명 수정, 100개 상품설명 입력, 303개 원본 상품명 별도 보존**.
- 상품 ID, 홈페이지 상품번호, 카페24 내부 코드, 기존 모델코드, 가격, 옵션 ID, 색상, 카테고리는 변경하지 않음.
- 아래 검토 사유는 **모델 또는 판매 구성을 새로 만들어낸 것이 아니며**, 실제 원본 정보가 불충분한 부분은 그대로 확인 대상으로 표시함.
- 가방 및 바퀴 포함 여부와 색상, 길이, 상판, 재질, 판매 수량 등 판매 구분 정보는 공유 상품명에 유지.
- 상품설명은 매장직원용 내부 메모. 원본에 없는 특징을 임의로 추가하지 않음. 설명이 비어 있는 상품은 확실한 내부 참고 정보가 없다는 의미.
- **이 변경은 신규 설치용 초기 상품 데이터에만 적용됨**. 이미 사용 중인 Windows SQLite DB는 수정하지 않음. 운영 DB 적용은 기존 변경사항 및 주문을 보호하는 별도 승인/검증 후 진행.
- `검토 필요` 사유가 있는 항목은 원본 홈페이지와 직원 확인 없이 모델코드나 판매 옵션을 확정해선 안 됨.

## 요약
- 원본 상품 수: **303개**
- 상품명 변경: **303개**
- 상품설명 입력: **100개**
- 카페24 P코드가 기존 `code` 필드에도 남아 있는 상품: **43개** (기존 연결을 보호하려고 자동 교체하지 않음)
- 복수 판매 옵션을 가진 원본 상품: **33개**
- 별도 수동 확인 항목: 상판 타입 충돌 4개, 중복 이름 2개, 원본 치수/높이 확인 8개 (서로 중복될 수 있음)

## 원본 옵션 표기 중 확인된 정정
기존 `바퀴 추가 안함`은 `바퀴 미포함`으로, `바퀴 추가`는 `바퀴 포함`으로 바꾸었음. 대상은 사이트 상품번호 **134, 135, 136**의 판매 옵션 6개이며, 옵션 ID/가격/수집 시점은 보존. 변경 전 옵션 문자열은 역사적 원본인 `catalog.json`에 남아 있음.

1. 검토 사유가 표시된 상품의 실제 모델코드, 상품 구성, 상판 및 규격을 원본 상세페이지 또는 상품 담당자의 근거로 확정.

3. 기존 운영 DB를 일괄 덮어쓰지 말고, 기존 주문/가격/거래처 정보와 충돌하지 않는 변경 절차를 별도로 승인받은 후 적용.
