# v0.8.09 Excel 규격 및 최종 보관 정책

원 통합 인계서의 A:O 15열 지시와 충돌하면 이 정정과 실물 파일을 우선합니다.

- 실물 기준: 20261105(매장2).xlsx. 데이터 행은 없으며 헤더·열 위치 검증용입니다.
- 물리 열 A:P 16개, 업무 필드 15개. J 공백. K 메시지. L 송하인명, M (송)우편, N (송)주소1, O (송)전화, P (송)핸드폰. E 제목은 수하인핸드폰번호.
- 발송: YYYYMMDD(매장N).xlsx. 일별 사용 순번과 기존 출력 이력을 확인해 증가시키고 날짜가 바뀌면 다시 1부터 시작합니다. 기존 파일을 덮어쓰지 않습니다.
- 공장 회신: YYYYMMDD(공장N).xlsx. Q는 운송장번호 열입니다. 앞자리 0을 보존하며 수식·정밀도 손실 의심 값은 보류합니다. 나머지 필드는 확인 가능한 헤더로 식별하고 실제 공장 양식을 추측하지 않습니다.
- 매장N과 공장N의 같은 순번을 대응 관계로 간주하지 않습니다. 수취인·주소·연락처와 실제 발송 스냅샷으로 유일한 배송 건만 연결합니다.
- 실제 운임·송장만 반영하며 판매가격·고객 청구 운임·입금·확정 및 출력 스냅샷은 보존합니다. 중복·충돌·미일치는 직원 확인 대상으로 남깁니다.

최종 사용자 주차 정정은 원문의 1~4주차·7일 구간 제안 및 월을 넘긴 주를 한 폴더에 모으는 설명을 대체합니다.

1. 월요일~토요일을 묶고 일요일은 직전 월~토에 연결합니다. 즉 월요일 시작·일요일 종료 달력 행 기준입니다.
2. 월에 따라 5·6주차를 허용합니다. ISO 연간 주차를 쓰지 않습니다.
3. 파일은 업무 날짜의 연·월 폴더에만 존재합니다. 월을 걸친 주도 다른 월로 이동하거나 중복 보관하지 않습니다.
4. 예: 2026-11-30 → 2026년/11월/6주차, 2026-12-01 → 2026년/12월/1주차.
5. 하위 폴더는 매장 발송 / 공장 회신으로 구분합니다. 필요한 폴더만 자동 생성합니다.
6. 공장 회신은 수신일 대신 파일명 업무 날짜를 사용합니다. 원본 내용을 보관하고 파일 경로와 이력을 연결합니다. 같은 파일명에 내용이 다른 경우 덮어쓰지 않고 보류합니다.
